# Retail Sales Analysis Dashboard

## Project Overview
This project presents an interactive Retail Sales Analysis Dashboard built in Microsoft Excel to analyze sales performance, customer behavior, and product trends.

## Objectives
- Track total sales and revenue
- Analyze sales by category and region
- Identify top-performing products
- Monitor monthly sales trends
- Provide interactive filtering using slicers

## Dashboard Features
- KPI Cards (Total Sales, Profit, Orders)
- Sales Trend Analysis
- Category-wise Sales Distribution
- Region-wise Performance
- Top Products Analysis
- Interactive Slicers

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting

## Key Insights
- Identified top-selling product categories
- Compared regional sales performance
- Analyzed monthly sales growth trends
- Highlighted high-revenue products
